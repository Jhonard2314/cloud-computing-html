What is Cloud Computing?

Cloud computing is the delivery of computing services such as servers, storage, databases, networking, and software over the internet, instead of relying on a local computer or physical hardware. Instead of storing files on a personal hard drive or running programs from a single machine, cloud computing allows users to access these resources remotely through the internet, usually from a company that manages and maintains the infrastructure.

Cloud Computing Services

Google Drive

Google Drive is a cloud storage service that allows users to store, share, and access files such as documents, photos, and videos from any device with an internet connection.

Amazon Web Services (AWS)

AWS is a cloud computing platform that provides services such as computing power, storage, and databases, which businesses use to build and run applications without maintaining their own physical servers.

Microsoft Azure

Microsoft Azure is a cloud platform used for building, testing, deploying, and managing applications and services through Microsoft-managed data centers.

Common Cloud Computing Concepts

  • Software as a Service (SaaS)
  • Platform as a Service (PaaS)
  • Infrastructure as a Service (IaaS)
  • Cloud Storage
  • Data Backup and Recovery
